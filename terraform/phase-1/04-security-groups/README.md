# Innstructions for the use of this terraform files

## Goal

This module (`04-security-groups`) creates security groups that requires the use of the `vpc_id` generated by the module (`02-vpc`).
Therefore, you **must execute the module (`02-vpc`) first**, so the rest of the resources can correctly reference the (`vpc_id`).

In this path `terraform/phase-1/02-vpc/outputs.tf`, the `vpc_id` is stored in the Terraform state file (`terraform.tfsate`).
Then, in the `terraform/phase-1/04-security-groups/data.tf`, we import that state using `terraform_remote_state`

---

## Step 1: Execute the `02-vpc` Module

```bash
cd terraform/phase-1/02-vpc
terraform init
terraform plan
terraform apply
```

Make sure that you have in the 02-vpc/outputs.tf

```
output "vpc_id" {
    value = aws_vpc.dev_vpc.id
}
```

## Step 2: Reference `vpc_id` from Remote State 
In the `04-security-groups/data.tf` file, is declared the remote sate like this:

```
data "terraform_remote_state" "vpc" {
    backend = "local"
    config = {
      path = "../02-vpc/terraform.tfstate"
    }
}
```

## Step 3: Execute the `04-security-groups` Module
Once the `vpc_id` is available through the remote state, this module can be run

```bash
cd terraform/phase-1/03-security-groups/
terraform init
terraform plan
terraform apply
```
